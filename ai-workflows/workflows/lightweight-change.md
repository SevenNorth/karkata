# 轻量修改工作流

1. 读取 `AGENTS.md`、目标源码和相邻测试，确认不触发完整流程条件。
2. 在对话中用一至三句话说明目标行为、影响范围和拟新增的失败测试。
3. Red：编写聚焦测试并运行，确认因目标行为缺失而失败。
4. Green：最小化实现，不夹带重构或预设扩展，使聚焦测试通过。
5. Refactor：只清理本次变更造成的结构问题，保持测试绿色。
6. 运行受影响包测试和 `npm run check`；无法运行时说明原因。
7. 汇报关键改动、Red 证据、验证结果和剩余风险。

实现中一旦发现公共契约、异步竞态、跨包、构建发布或高风险影响，立即停止轻量流程并切换到完整流程。
